# Independent holistic review: clay-regency-stucco-terrace v001 (RLASM v6.1 architectural clay)

Reviewer: independent (did not build the candidate). Evidence used: only `sources/front.png`, `sources/oblique.jpg` and `sources/top.jpg`, all 18 `renders/*.png` opened at full resolution, and the four `boards/*.png`. Zoomed crops for inspection only were written to `/tmp/claude-0/-home-user-CityPrompt/18c9e177-8a96-5987-8fce-7444c75d018c/scratchpad/indep-review-regency-v001-crops/`. I did not use metadata, build reports, evidence JSON or the builder's notes as proof.

## 1. Verdict

**VISUAL_REWORK_REQUIRED.** The model has the right Regency vocabulary and good opening depth, but the facade programme is rotated 90 degrees against the governing top view and oblique: one pediment front plus two long porch-and-fin fronts became two pediment ends plus one porch front. It also has seven production-blocking fidelity and finish defects: a squat mansard, non-Corinthian capitals, square porch piers, a missing pediment-front porch, open corner joints, a blank terrace box and near-invisible rustication.

Counts: P0 = 1, P1 = 7, P2 = 8

## 4. Camera validity

- **front:** Valid but weak. The target is legible and nothing is clipped. Tree crowns cover part of the central porch, and the corner-on framing differs from the source front's long-face framing (P2, #15).
- **front_corner, aerial, top, left_side, right_side, rear_side:** Valid. The whole envelope is in frame and legible.
- **rear, rear_north:** Only the context terrace and the main roof are legible, and the north face of the main building is occluded by the party-wall terrace. This is consistent with the source condition (the north side is party wall), so it is not counted as invalid, but these views give no main-building elevation evidence (P2, #15).
- **Detail views (facade_close, architecture_close, glass_close, porch_balcony, giant_order, end_pediment, mansard_dormers, east_side, interior):** All valid. glass_close is about 40% covered by a tree crown but still shows the window, balconette, column base and porch-balcony joint it is meant to show.
- No view has its target clipped or illegible.
