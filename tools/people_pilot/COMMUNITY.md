# Local twenty-adult expansion, 2026-10-22

Twenty `people-community-*` adults extend the original three. The original GLB
and thumbnail byte locks remain unchanged; their catalogue descriptions now
explain saved actions. No asset was downloaded, purchased or generated by an AI
provider. Nothing was pushed, deployed, or added to ordinary Git as binary data.

The official Quaternius CC0 Standard archives already used by the pilot provide
two athletic adult anatomical bases, six hairstyles (including bald/beard), eyes
and Walk/Idle motion. New derivatives vary height, width/depth, facial width,
garment fit, collar, hem, coat extension, trouser taper and palettes. These are
stylized low polygon derivatives; they are not twenty independently sculpted
anatomies or photoreal people. Clothes remain long-sleeved with full trousers.

`community_designs.json` is the finite design inventory. `build_community.py`
reuses the pilot builder through an explicit optional pre-export callback. The
pilot builder's default behavior is unchanged. The first actual-model pilot was
reviewed before the remaining batch. A failed Blender operator interception was
caught by inspecting exported root metadata and scale, then replaced with the
explicit callback. A regression assertion now rejects missing shape edits.
Close review subsequently exposed male neckline gaps; a neck underlay and
continuous collar repaired only the ten affected male designs.

Measurement reloads each exported GLB in Blender and samples 41 times per clip:
1,640 posed bounds/sole samples across the twenty actors. It checks finite
accessors, skin weights/joint bounds, in-place Walk/Idle clips, texture dimensions,
self-contained bytes, metre heights and sole contact. Three.js GLTFLoader also
loads every model and evaluates both clips. Its Node raster shim supplies PNG
dimensions only; actual texture pixels and visible materials are independently
checked by Blender renders. This is not a browser GPU/frame-rate benchmark.

The actual-model review includes all twenty thumbnails/contact-sheet entries,
plus portraits and rear walking views of Ava, Noah, Zara and Jules. Collar and
shoulder geometry remains visibly simple at close range, with no cloth simulation.
Every runtime action uses the shared procedural pose system; only Walk/Idle are
native clips, and running uses faster Walk. Walking needs a clear level path,
sitting needs a student-provided seat, and there is no automatic obstacle
avoidance, chair detection or pathfinding. The separate app integration review
owns fifteen-action previews/captures and independent instance behavior.
