# Finite housing teaching batch

Two original teaching designs fill forms absent from the 252-family source
inventory: a wartime/Victory house and postwar side-split. Earlier Vancouver
Special, laneway and walk-up packages exist; their missing picker coverage is
reconciliation work and is not counted as a new modelling gap here.

`cards.json` keeps use/form, aesthetic, era and planning connections separate.
Dates concern design associations, never a fictitious construction year. Tenure
and affordability remain unknown. Historical sources are linked on each card.

`build.py` reuses construction/evidence primitives, not a sibling's composition.
Sources live under `frontend/public/archetypes/buildings/housing-teaching/`;
all candidates, rejected attempts and originals stay in
`C:/dev-artifacts/CityPrompt/housing-teaching-20261025`.

Dry-run, build Victory, inspect every exact-GLB render and all phone boards,
obtain independent holistic architectural-clay review, then build the side-split.
No model is activated by this tool. Runtime checks remain NOT TESTED. These are
texture-free clay deliveries; catalogue reference originals remain the future
picker/render authority, and a textured keeper is a separate review class.

Victory enrolls four compatible source roles. The side-split enrolls five:
front/oblique/top plus the compatible earlier front/oblique. Its earlier top
uses an incompatible roof orientation; both proposed rear-left views contradict
the single-window left end. Whole originals and rejection notes are preserved.
The unseen side-split rear and internal unequal floor offsets are declared
inferences, not historic-plan reconstructions. Candidate evidence retains the
exact scripts that produced it; later source edits do not rewrite that snapshot.
