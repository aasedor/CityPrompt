| --- | --- | --- |
| Correct style, wrong building | plan, ratio, roof, bay or program inferred from category | remeasure locked views and rebuild constructor before materials |
| Detailed but generic facade | specimens substituted for registered identity | add bounded orthographic identity authority on audited datums |
| Generic material despite source name/hash | palette or procedural recipe matched, morphology did not | derive exact-family role specimens and review scale/axes in pixels |
| Two colours for one stone building | semantic roles approved independently | establish one substance-level hue/finish authority; vary relief/roughness only |
| Skewed emblem or cropped architecture inside plaque | perspective crop mounted directly | isolate/rectify a native-aspect orthographic identity derivative |
| Good front, blank side/rear | hero elevation hid carrier architecture | continue the same bay, material, opening and roof grammar around envelope |
| Flat, dark or glowing window | carrier was not cut or layers are coplanar/reversed | cut every owner and rebuild exterior-to-interior section obliquely |
| Logs continue through glass | grille/pane pasted on uninterrupted courses | terminate courses at jambs; expose cut ends and recessed assembly |
| Floating dormer/window | body placed from nominal boundary, not roof plane | derive from slope, cross cheeks into roof, cut full depth, seat cap/flashing |
| Black roof slot or floating ridge | intersection lacks bounded weathering owner | rebuild closed ridge/valley/cap graph and prove aerial/rear-side |
| Glass hall looks like greenhouse | shell built without transport/civic program | add tracks/platforms/canopies/concourse/furniture/circulation and interior views |
| Gate exists but route is blocked | facade appearance replaced plan/circulation | create a clear walkable axial passage and prove it through the gate |
| Phone board fails after metadata pass | counters were treated as visual proof | demote/supersede, record blocker, rerender, repeat independent review |
| Scoped pass says keeper; later defect appears | category closure conflated with holistic approval | preserve scoped review, rescind promotion, run full adversarial regression |

For every failure record the exact view, symptom, cause, affected physical
owner, finite fix, version advanced from/to, and regression views required.
