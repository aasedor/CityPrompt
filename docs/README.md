# Documentation index

`docs/` holds the canonical method, policy and setup documents alongside
dated review records. Dated files (`*_YYYY-MM-DD.md` or `.json`) are
historical evidence of a specific checkpoint; when two disagree, the later
date reflects the current state. Undated files are the living references.

- [LOCAL_SETUP_GUIDE.md](LOCAL_SETUP_GUIDE.md): beginner-friendly installation.
