## Production contract

`publicRealmRelease.ts` and `fixed_public_realm.py` independently check the
release namespace, hash-bearing URL, revision, exact variant, definition version,
fixed rectangle and authored ground ownership. Production accepts only `ready`
or saved `retired` rows with a complete exact-runtime visual review (zero P0/P1)
and an exact-runtime interaction/capture review, each carrying an evidence hash.
Development can rehearse the finite `runtime_trial` rows while those gates remain
open. AI route/planner claims are rejected.

The existing native layer owns rendering, centering, selection and capture.
Shared prepared site terrain remains mandatory. Unavailable, stale or unapproved
saved release claims retain an unsupported marker and block capture rather than
mounting a replacement model. Existing fixed-scene guards now also recognize the
release namespace, preventing park-outline edits and procedural street controls,
walking assumptions, duplication and automatic junctions on these complete scenes.
Ordinary fixed object duplication, move, rotation and undo remain shared systems.
