Pro Tips

Small things that make a big difference

🎯

Always set archetypes

A zone with "Parisian Mid-Rise" renders limestone and zinc. A generic "building" gets generic results. Archetypes are the #1 quality lever.

🔍

Zoom in for detail

Rendering 5 buildings up close produces sharper materials than 25 buildings zoomed out. Render in sections for best quality.

📷

Photomontage is sharpest

It simulates a real Hasselblad camera sensor. Best for client presentations and realistic outputs.

⚡

Flash 3.1 > Pro 3

Flash follows zone boundaries more reliably. Pro has more reasoning but Flash is optimized for image generation. Use Flash 3.1 for most renders.

📐

Oblique angle works best

Tilt the map to 45-60 degrees before rendering. You see both rooftops and facades — the AI handles this angle best.

🛤

Set realistic road widths

Pedestrian: 3-5m. Local: 8-10m. Main: 18-22m. Boulevard: 28-34m. The width shows on the map and affects renders.
