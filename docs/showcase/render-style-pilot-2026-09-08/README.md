# City Prompt visual review

Latest Currie Commons render-style trial, 8 September 2026. Seven existing GPT Image 2 renders, five source captures and four app screenshots. No new render calls were made. Earlier failures are retained for comparison, not presented as accepted designs. Full-resolution files are unchanged originals.

Open [the gallery](gallery.html) locally for a browsable view. On GitHub, use the images below. Files use Git LFS; run `git lfs pull` after cloning.

See [the trial report](../../RENDER_STYLE_DETAIL_PILOT_2026-09-08.md) for findings and limitations.
