# Five brand-new RLASM confirmation buildings

This finite batch proves five new archetypes using the full RLASM sequence:

1. lock three reference views;
2. decompose every unique architectural role into cards;
3. generate one reference-specific atomic facade card with transparent openings;
4. mount it on a physical Blender shell with modeled sides, roof, openings and depth;
5. use reusable neutral low-iron physical glass with scene-only reflections;
6. export the actual GLB and render front, front-corner, aerial, side and detail views;
7. reject non-overwriting candidates when carrier geometry collides with the locked facade;
8. require zero floating contacts, zero generic material fallbacks and a 95+ pragmatic visual score.

The five accepted candidates are Barcelona Mercat, Japanese Machiya Mixed Use,
Deco Theater Mainstreet, Mountain Alpine Chalet, and Brutalist Institutional.

The `.blend` and `.glb` files remain in ignored artifact storage. This Git
showcase contains only reviewed images, prework sheets and compact QA evidence.
