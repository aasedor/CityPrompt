# RLASM v5 independently passed three-family comparison

These are the first three v5 candidates promoted after a complete
source-locked geometry, architecture, material, optical-depth and secondary-
elevation review. Each candidate was independently re-reviewed against its own
authoritative front, oblique and top sources plus every mandatory model camera.
All three decisions are `PASS_ZERO_P0_KEEPER_READY`.

The earlier four-item “current reviewed keepers” board is superseded by the
full re-scan: those four remain in `visual_rework_required`. This package adds
three independently approved keepers; it does not silently promote the older
four.

## Audit records

- [`RLASM_PROVEN_BUILD_RECIPE_V5.md`](RLASM_PROVEN_BUILD_RECIPE_V5.md) is the
  concrete start-to-finish recipe used for the three passed buildings,
  including family constructors, commands, visual gates, and promotion steps.
- `phone-review-manifest.json` records image bytes and SHA-256 hashes.
- Each `*-independent-review.json` records the separate reviewer, evidence
  roles, zero unresolved blockers and closed findings.
- `keeper-review-task-list.json` records the current batch states.
- `RLASM_LATEST_METHOD_V5.md` remains the cumulative learning record and links
  back to the proven execution recipe.

The image panels deliberately include the authoritative source beside the
locked model camera. Builder object counts, source hashes and zero-fallback
counters remain audit evidence only; they do not substitute for the visible
comparison or independent approval.
