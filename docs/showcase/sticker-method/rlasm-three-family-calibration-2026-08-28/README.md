# RLASM three-family catalogue-conditioned calibration

This reviewed set compares three exact catalogue source contracts with their
latest physical RLASM models:

- `courthouse_art_deco / variant_1`
- `grand_log_lodge / variant_0`
- `vernacular_courtyard_chinese_siheyuan / variant_0`

## Review decision

All three builds have complete physical envelopes, source-specific procedural
materials, zero generic fallbacks, zero facade stickers, complete multi-view
render sets, and preserved GLBs. All three nevertheless remain
`visual_rework_required` after the full phone source/model comparison.

They are **not keepers**. Independent keeper approval is blocked until the
architectural discrepancies in each `full-geometry-architectural-review.json`
are fixed and the complete comparison is repeated.

The overview image is the fastest phone review. The three individual boards
show two authoritative source roles, three matching model proofs, exact GLB
hash prefixes, and the open architectural blockers. Every invalid or rejected
iteration remains preserved in the external working artifact; only these
intentional reviewed images and evidence records are promoted here.

## Method result

The calibration proved that source provenance, physical completeness and zero
generic materials are necessary but not sufficient. RLASM must additionally
encode family-specific high-level geometry for civic shoulder/relief hierarchy,
joined log-gable/chimney/porch construction, and lifted ceramic eaves/gate caps/
courtyard landscape before bounded batch generation can be trusted.
