# RLASM three-family builder-pass review

> **Superseded material decision.** The geometry and constructor findings in
> this package remain valid, but the overall builder-pass label was rescinded
> after independent phone review exposed shared generic material recipes. Use
> the adjacent `rlasm-three-family-material-correction-2026-08-28` package for
> the corrected courthouse v8, lodge v13, and Siheyuan v8 evidence.

This package contains the deterministic phone-scale source/model comparison
that followed the rejected three-family calibration package. Each model uses
the exact compatible catalogue images recorded in its review evidence, a
complete physical envelope, zero generic material fallbacks, and zero facade
stickers.

The builder review passed after preserving and correcting the failed
iterations:

- Art Deco judicial courthouse v5: occupied setback crown; piers between,
  rather than through, window bays.
- Grand log lodge v10: paired roof planes descend from their ridges; occupied
  timber gable fields, rakes, windows, porch and chimney remain visible.
- Chinese Siheyuan v5: bounded dark roof ridges, scaled moon-gate cap, lifted
  closed roofs, open court, layered galleries and finished rear elevation.

`PASS_BUILDER_REVIEW_AWAITING_INDEPENDENT_APPROVAL` is deliberately not a
keeper decision. The builder found zero remaining geometry or architectural
blockers in the locked review set, but an independent reviewer must approve
keeper promotion. The older calibration folder remains in Git as rejected
evidence and was not overwritten.

Start with `rlasm-three-family-phone-overview.png`, then open the individual
1080 × 1920 comparison images for source, oblique, aerial and detail proof.
The JSON files contain source hashes, GLB hashes, the discrepancy ledger, and
the explicit pending independent-approval state.
