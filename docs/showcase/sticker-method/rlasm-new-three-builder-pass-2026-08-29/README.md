## Audit trail

- `RLASM_PROVEN_BUILD_RECIPE_V5.md` records the repeatable construction steps
  and the lessons learned while building this new-family batch.
- `RLASM_LATEST_METHOD_V5.md` is the cumulative method specification.
- Each `*-builder-evidence.json` records its exact source lock, required render
  roles, registered identity count, and zero-fallback result.
- Each `*-builder-review.json` records the bounded visual decision and confirms
  that independent approval is still pending.
- `phone-review-manifest.json` records the bytes and SHA-256 hash of every
  published phone image.

The source/model panels are the visual proof. Object counts and metadata are
supporting audit evidence and never substitute for architectural review.
