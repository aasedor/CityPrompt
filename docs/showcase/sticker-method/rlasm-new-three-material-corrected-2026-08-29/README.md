# Three new RLASM v5 buildings — exact-source material correction

This package supersedes the earlier `rlasm-new-three-builder-pass-2026-08-29`
visual package. The earlier candidates are preserved, but their builder passes
were rescinded after phone review showed that their materials still read as
generic beside the locked archetype sources.

The corrected candidates use reviewed, shadow-neutral material sheets
conditioned from the exact locked source images. Each dominant material role
records its bytes and SHA-256 in the candidate prework manifest. Physical
world-space mapping, complete-envelope continuity, true glazing recesses, and
all opaque carrier cuts were reviewed again.

These are **builder-reviewed candidates, not keepers**. Independent zero-P0
approval is still required before keeper promotion.

## What changed

- Station: exact-source Victorian brick, honey sandstone, charcoal slate,
  oxidized iron, deeper true window sections, and shared physical mapping.
- Hospital: exact-source Carrara and green serpentine, repaired side-window
  continuity, removed overlap ghost bays, and closer optical review framing.
- Fire station: exact-source aged ashlar, dressed carved stone, blue-grey
  slate, oak and copper; every front and side dormer now cuts both finish skin
  and structural wall.
- All three: zero generic fallbacks, one bounded registered identity, eleven
  review renders, complete source/material hashes, and preserved rejected
  versions.

`RLASM_PROVEN_BUILD_RECIPE_V5.md` and `RLASM_LATEST_METHOD_V5.md` record every
reusable lesson. Builder evidence and review JSON are supporting audit records;
the source/model panels remain the visual proof.
