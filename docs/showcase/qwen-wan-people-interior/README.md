# People indoors: Qwen image and Wan animation

One image trial with two adults close to the camera inside a brick residential lounge, followed by one animation of that exact finished image. Photographic realism takes priority over exact architectural matching.

## Qwen Image 3 image

[Open full-size image](https://media.githubusercontent.com/media/aasedor/CityPrompt/codex/people-interior-phone-review/docs/showcase/qwen-wan-people-interior/qwen-people-interior.png)

![Two adults close to the camera in a sunlit brick lounge](qwen-people-interior.png)

Qwen followed the prompted move indoors and produced convincing foreground faces, fabrics and visible hands. The exterior reference remains recognizable through the window.

## Wan 3.0 animation

[Watch or download the eight-second video](https://media.githubusercontent.com/media/aasedor/CityPrompt/codex/people-interior-phone-review/docs/showcase/qwen-wan-people-interior/wan-people-interior.mp4)

The animation uses the image above as its sole input. Across sampled frames, both adults remain recognizable and the hands, clothing and interior stay visually coherent. Wan adds a broader smile and lowers the mug to the table, exceeding the requested restraint.

- Image: Qwen Image 3 through fal, 1536 x 864 PNG.
- Animation: Wan 3.0 through fal, 1280 x 720 MP4, eight seconds, 30 fps, silent.
- Exactly one image generation and one video generation for this trial.
- Generated 2026-10-03; reviewed locally before publication.

These are illustrative model trials, not an approved design or catalogue asset. The media files use Git LFS.
