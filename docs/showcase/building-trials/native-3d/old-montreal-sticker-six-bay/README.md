# Old Montreal Sticker Method — six-bay pilot

This is a phone-friendly visual checkpoint for the first scaled derivative made
after returning to the approved Sticker Method.

**Review status:** `visual_review_pending` — structurally validated, but not yet
marked production-approved or accepted as a visual baseline.

- Direct Blender 5.1.2 renders of the actual assembled 3D model.
- No GPT image generation, AI enhancement, or paint-over.
- 30 × 20 m footprint, three storeys, and six complete 5 m façade bays.
- 36,352 triangles in the assembled GLB.
- 6,541 surface faces audited with zero ownership failures.
- Structural validation passed.
- Known optimization debt: 1,815 materials and a 17.1 MB assembled GLB exceed
  the production delivery target. This does not invalidate visual review, but
  it must be resolved before a catalogue wave.
