# Shared park equipment kit v1

This review set covers the first reusable, metric park-equipment family for the LEGO park builder. The models are authored as deterministic Blender geometry and use the park archetype catalogue for silhouette, material character, placement, and human-scale cues. No people are included in the generated geometry.

## City Prompt pilot

The single-zone basketball pilot uses a regulation-proportioned court semantic, two separately placed hoop GLBs, and the shared furniture kit. The placement solver treats the court and hoop clearances as fixed program space, so incidental furniture stays outside play. The legacy AI ground drape was disabled for this review; the visible court is generated by the deterministic LEGO ground-skin renderer.

`basketball_court_v0` is now an executable Public Realm LEGO family. A future Generate action compiles the court, exact hoop assets, and shared equipment contract directly and identifies the surface as archetype-owned, preventing a new legacy AI drape call.

The project still contains a separate LEGO-family building. It was intentionally kept outside these close equipment-review frames.

## Meshy decision

Meshy was not needed for this batch. Hoops, tables, bins, racks, and fountains benefit from known dimensions, clean pivots, low triangle counts, and repeatable collision footprints, which are more reliable with authored geometry. Meshy remains useful for later irregular assets such as sculptural play pieces, carved natural forms, or bespoke public art, followed by metric cleanup and pivot validation in Blender.
