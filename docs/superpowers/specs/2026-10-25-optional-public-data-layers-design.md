# Optional public data layers

The user has selected optional map-layer tick boxes and asked that the program stay fast. Reuse the existing Map layers menu and reference-vector renderer. All choices start off; choices are personal session state, scoped by project. They do not import data, alter a proposal, or add finance worksheets.

Offer recent assessment history, building permits, development permits, public water mains, suburban growth/servicing, 2021 community population profiles, historic resources, public trees, 2022 canopy, community services, and schools. Each uses a small allowlisted Calgary Open Data request around a drawn site boundary (250 m buffer). Panning without a boundary never initiates downloads. Community profiles link to the full census profile for other topics. CMHC rental context and off-site levies are explicitly labelled source-reference cards, not invented parcel data or calculators.

Performance constraints: no requests or geometry for unticked options; at most four map datasets and two concurrent requests; no polling or focus refetch; ten-minute fresh cache; abort obsolete work. Restrict queries to Calgary envelopes under 4 km² and 4 km in either dimension, at most 301 source rows, 2 MiB responses, 4,000 displayed coordinates/estimated ground samples per dataset (including the renderer's line subdivisions), and a 20-second timeout. Public point symbols use one terrain anchor and a small flat marker; existing transport-stop drawing is unchanged. Clip geometry to the local envelope. Warn whenever results are truncated, skipped, or absent. Cache keys include project and bounds, so old site results never appear at a new site. Existing capture exclusion keeps reference overlays out of photorealistic source captures.

Show dates, source links, attribution, and short teaching limitations. Draw only original source boundary segments inside the nearby window, never artificial polygon-cut edges. Retain records for an area enclosing the window even if it has no boundary in view, with an explicit explanation and a loaded-record count. Assessments are not sale prices; permits are not completion evidence; public mains do not establish available capacity; census values describe whole communities; canopy is from 2022; heritage inventory is distinct from legal designation. Retain exact assessment roll identifiers and combine only matching identifiers. Do not request personal applicant/owner fields.

Verification: focused tests for request/geometry limits, cancellation, cold-start inactivity, cache reuse, project/site isolation, empty/error recovery and accessible tick boxes; existing reference tests; TypeScript check; local browser student trial. No paid generation, catalogue edits, push or deployment.
