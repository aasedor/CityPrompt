# People and photographic video pilot

The user approved a few original character designs staged in a real CityPrompt street, using the Blender-town example as a quality benchmark. Creative decisions are delegated; no intermediate approval is required. The authorized paid batch is at most ten four-second Omni edits, never ten eight-second edits. No production deployment or code push is part of this pilot.

## Deliverable

Build three distinct adult characters with realistic human proportions, plausible clothing and walk/idle motion. A verified CC0 rigged base may be adapted with honest provenance. Preserve originals and keep heavy assets and QA outside the source tree. Animate by absolute capture time, with independent skeletons and materials, correct metre scale and feet on the authored sidewalk. Keep people opt-in and ordinary editing idle. Reuse Add Details placement, selection and persistence where practical; do not introduce crowd simulation or pathfinding.

Stage an authored local CityPrompt street with buildings, landscaping, street furniture and a nearby walking subject. Capture genuine 24 fps four-second clips through the existing native video workflow. Use a bounded optional photographic character-reference image, explicitly separated from the source video. Preserve existing eight-second workflows and exact-request replay. Validate media and credits before each paid call; retain receipts and results even when quality fails.

## Acceptance

- Free browser review of full gait cycles, ground contact, scale, camera framing and scene depth before paid trials.
- Test four/eight-second capture and backend validation, optional reference validation/privacy/idempotency, deterministic poses and independent instances.
- Record actual source/output duration, model, hashes, prompt, usage, estimated provider cost, and visual findings per paid call. Stop if a four-second edit is unexpectedly expanded until the cause is understood.
- Review full clips, not only successful API status or selected stills. Prioritize lifelike people, stable appearance, believable walking, photographic materials and recognizable architecture.
- Run narrow automated tests, type-check, scoped lint, configured build and an independent code/visual review. Disclose unavailable device performance tests and remaining fidelity limitations.
- Deliver the best video(s), source comparison, character previews, local scene link and clear implemented/tested status. No unapproved purchases, provider changes, production mutations or broad staging.
