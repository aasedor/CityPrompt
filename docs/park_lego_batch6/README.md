# Park LEGO batch 6

This bounded batch advances ten exact catalogue variants through the same
zero-call park LEGO pipeline established in batch 5. Each family owns an exact
program grammar, a reusable vertical equipment kit and a dedicated stationary
PBR skin library derived from its selected archetype render.

| Family | Exact catalogue variant | Locked composition rule |
|---|---|---|
| Outdoor ice rink | Multipurpose Pad v3 | One complete convertible pad inside permanent boards |
| Kayak launch | River Launch v0 | Dry staging to rack to accessible slide to floating dock |
| Tidal marsh | Cordgrass Boardwalk v0 | One elevated route ending at one overlook beside a tidal creek |
| Outdoor cinema | Park-Lawn Projection v1 | Screen, clear sightline lawn and rear booth on one axis |
| Food-truck plaza | Permanent Park v1 | Whole utility bays in an L around a pedestrian picnic court |
| Festival lawn | Great Lawn v2 | One contiguous everyday lawn with event infrastructure at the edge |
| Campus quad | Naturalized Meadow v0 | Gateway desire lines crossing through meadow rooms |
| Urban beach | Family Splash v2 | Sand, shallow splash, accessible boardwalk and shade bays |
| Velodrome | Open-Air v0 | One complete banked circuit, clear infield and home-straight support |
| Mountain-bike park | Skills and Dirt v2 | Connected pump loop, jump progression and non-crossing return |

People in catalogue renders are scale and use evidence only. Large buildings
remain separate building LEGO families. The generated skins use reference
colour statistics and role-specific procedural structure; source photographs
are never projected onto the 3D geometry.

The batch performs no paid image calls and no Meshy calls. The current kit is
procedural because the required boards, dock, racks, boardwalk, screen, trucks,
tables, sails, banked track, bleachers and earthwork modules are all bounded,
repeatable geometry.
